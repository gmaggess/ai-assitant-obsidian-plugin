# Crewline Learnings

Durable, shared context about **this repo** that crewline agents accumulate as they
work. Coders and reviewers read this file at startup and append to it when they
discover something worth remembering. The goal is compounding context — what one
agent learns, every later agent inherits.

## How to use this file

- **Read it at startup.** Treat every entry as a constraint or hint for the work at hand.
- **Append on genuine discovery only.** A learning is durable repo knowledge: a
  convention you had to infer, a pitfall that cost you a round, a pattern confirmed
  to be the right one, a maintainer preference. Do **not** log task-specific notes,
  one-off bug fixes (those live in the commit), or anything already in `CLAUDE.md`.
- **De-duplicate before appending.** Scan the relevant category first. If a matching
  entry exists, refine it in place instead of adding a near-duplicate. Keep this file
  curated, not append-only.
- **Keep entries one or two lines.** Lead with the rule, then a short `—` why/where.
- **Cite evidence** with a `path/to/file.ext:line` or issue/PR reference when useful.
